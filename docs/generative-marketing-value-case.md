## 一、要证明的不是"AI 能做"，而是"客户愿意持续付费"

常见的立项陷阱是证明"AI 生成的素材比客户自己做的好"——这太容易了，也因此没有说服力。很多 OPC 用户原来就是手机拍图、自己写文案，随便找个设计师都能比他们做得好，不需要 AI。

**真正需要回答的三个问题：**


| #   | 问题                                                 | 为什么重要                           |
| --- | -------------------------------------------------- | ------------------------------- |
| 1   | 我们的 AI 方案 vs 客户能买到的替代方案（外包设计师、Canva、ChatGPT），优势在哪？ | 证明的不是"AI 比业余好"，而是"AI 比市面上的替代品好" |
| 2   | 价值的核心来源是素材质量、受众定向、出价策略、还是全链路自动化？                   | 不拆清楚就不知道该把资源押在哪里                |
| 3   | 客户是否愿意为此持续付费，而不是用一次就走？                             | 效果好 ≠ 能变现，订阅模型需要持续价值            |

## 二、价值差异的三个层面

### 层面 1：效果差异 — "用了之后，广告表现好了多少？"

这是最硬的价值，直接影响客户的收入。


| 指标            | 含义                    | 量化方式                                |
| ------------- | --------------------- | ----------------------------------- |
| CTR（点击率）      | 广告被点击的概率              | AI 素材 vs 对照组，同受众、同时段 A/B 测试         |
| CVR（转化率）      | 点击后完成购买的概率            | 分流测试，追踪到最终购买事件                      |
| CPA（单次获客成本）   | 获得一个客户花了多少钱           | 同 Campaign 内对比，= 花费 / 转化数           |
| ROAS（广告支出回报率） | 每花 1 块钱赚回多少           | = 收入 / 广告花费                         |
| 素材生命周期        | 素材从上线到 CTR 明显衰减的天数    | 追踪 CTR 衰减曲线，定义"疲劳"阈值（如 CTR 下降 >20%） |
| Meta 质量评分     | Meta 对广告素材的质量、互动、转化排名 | Meta Ads Manager 直接可查               |


**关键注意事项：**

- 对照组不能只是"客户原来的烂素材"，还需要和"客户花 $200 外包的素材"对比
- ROAS 提升需要做归因拆解（见第三节），不能笼统地说"提升了 X%"

### 层面 2：效率差异 — "即使效果差不多，也帮你省了大量时间和钱"

这对时间极度稀缺的 OPC 用户可能是更核心的价值。


| 指标      | 含义                     | 量化方式                    |
| ------- | ---------------------- | ----------------------- |
| 素材产出时间  | 生成一套可投放素材的耗时           | AI: 计时；人工: 用户自报或外包周期    |
| 素材产出成本  | 一套素材的实际花费              | AI: 系统成本分摊；人工: 设计师/外包报价 |
| 可测试变体数量 | 同一时间窗口内能产出多少组可测试素材     | 直接计数                    |
| 端到端上线时间 | 从"我想推这个产品"到"广告开始跑"的总耗时 | 计时：包括素材制作 + 广告配置 + 审核提交 |
| 迭代响应速度  | 发现素材疲劳后，换新素材上线的耗时      | 从告警触发到新素材上线的时间差         |


**预期量级：**

- 时间：从 2-3 天 → 5 分钟（约 500x 提效）
- 成本：从 $150-300/套 → 接近 $0
- 变体数量：从 2-3 套/周 → 10+ 套/次

### 层面 3：能力差异 — "以前做不到的事，现在能做了"

这是容易被忽略但可能最有说服力的维度——不是"做得更好"，而是"从不可能到可能"。


| 能力     | 客户原来的状态               | 用了 AI 之后                   |
| ------ | --------------------- | -------------------------- |
| 多市场投放  | 只会投一个市场，不懂其他市场的文案风格   | AI 生成 8 种语言本地化文案，可同时测试多个市场 |
| A/B 测试 | 没有足够素材做测试，全凭直觉        | 自动生成多变体 + 自动分配预算 + 自动关停差的  |
| 数据驱动优化 | 看不懂 Meta 后台数据，不知道该调什么 | AI 自动分析 + 推送建议 + 一键执行      |
| 预算保护   | 不知道什么时候该止损，经常烧完预算才发现  | 自动止损机制，触发即暂停               |
| 持续优化   | 广告上线后就不管了，直到钱花完       | 每日自动监控 + 优化建议 + 素材轮换       |

## 三、价值归因拆解 — 搞清楚价值到底从哪来

全链路 ROAS 提升是一个混合数字，决策层会追问"到底是哪个环节在创造价值"。需要做单变量对照实验：

### 实验设计


| 实验组      | 素材        | 受众定向      | 出价策略      | 验证目标        |
| -------- | --------- | --------- | --------- | ----------- |
| A — 基线   | 客户原素材     | 客户原设定     | 客户原设定     | 对照组         |
| B — 素材隔离 | **AI 素材** | 客户原设定     | 客户原设定     | 素材单独贡献多少？   |
| C — 定向隔离 | 客户原素材     | **AI 定向** | 客户原设定     | 受众定向单独贡献多少？ |
| D — 出价隔离 | 客户原素材     | 客户原设定     | **AI 出价** | 出价策略单独贡献多少？ |
| E — 全链路  | **AI 素材** | **AI 定向** | **AI 出价** | 全链路协同效应     |


### 预期产出

```
全链路 ROAS 提升 = X%
  ├── 素材贡献:  占比 a%
  ├── 定向贡献:  占比 b%
  ├── 出价贡献:  占比 c%
  └── 协同效应:  占比 d%  （E 的提升 > B+C+D 的总和，说明全链路有协同价值）
```

这个拆解直接回答"我们到底是一个素材工具，还是一个决策系统"——如果协同效应显著，就证明全链路的价值。

## 四、客户分层分析 — 对谁的价值最大？

不同客户获得的价值不同，需要分层验证：

### 按原有素材水平分层


| 客户类型  | 原有素材          | 预期价值           | 立项意义                   |
| ----- | ------------- | -------------- | ---------------------- |
| 无素材型  | 手机拍图、无设计      | 极大提升（从 0 到 1）  | 用户数量多，但价值证明弱（赢弱对手不算本事） |
| 初级素材型 | Canva 模板、简单设计 | 显著提升           | 最有价值的验证群体，数量大且有对比基线    |
| 专业素材型 | 有设计师或外包团队     | 效率提升为主，效果提升不确定 | 能赢这类客户才是真正的壁垒证明        |


### 按产品品类分层


| 品类特征    | 举例         | AI 适合度 | 原因                    |
| ------- | ---------- | ------ | --------------------- |
| 标品、视觉驱动 | 3C 配件、家居小件 | 高      | 产品图标准化，AI 背景合成效果好     |
| 时尚/审美驱动 | 服装、饰品      | 中      | 风格多变，AI 需要理解潮流趋势      |
| 非标/定制品  | 手工艺品、定制礼品  | 低      | 每件不同，难以批量生成           |
| 内容/体验型  | 课程、服务      | 待验证    | 依赖文案而非视觉，AI 文案能力可能是核心 |


### 按月广告预算分层


| 预算段          | 特征            | AI 的核心价值              |
| ------------ | ------------- | --------------------- |
| $100-500/月   | 每一分钱都敏感，试错成本高 | 降低试错风险（预算护栏）+ 首次投放成功率 |
| $500-2000/月  | 有一定投放经验，想提效   | 全链路效率 + 持续优化 + 多变体测试  |
| $2000-5000/月 | 有优化需求，考虑扩市场   | 多市场扩量 + 智能预算分配        |


**立项关键结论：明确我们的 sweet spot 在哪一层，资源优先投入那一层。**

## 五、付费意愿验证 — 不要问卷，要真金白银

效果数据和付费意愿是两回事。需要用实际行为验证：

### 方案：Landing Page Smoke Test + 小规模真收费


| 阶段                | 做法                         | 验证目标                |
| ----------------- | -------------------------- | ------------------- |
| 1. Smoke Test     | 上线定价页面，追踪"注册"和"选择付费计划"的点击率 | 多少人对价格有兴趣？          |
| 2. Free Tier 真实使用 | 开放免费版，看使用频率和留存             | 用户是"试一次就走"还是"持续使用"？ |
| 3. 付费转化           | 对活跃免费用户推送 Pro 升级，真收费       | 转化率多少？哪个功能是付费触发点？   |
| 4. 续费率            | 第 2 个月续费情况                 | 持续价值是否存在？           |


### 关键指标


| 指标             | 达标线 | 优秀线  | 不及格  |
| -------------- | --- | ---- | ---- |
| Free → Pro 转化率 | 3%  | 7%+  | <2%  |
| 第 2 个月续费率      | 80% | 90%+ | <70% |
| 月活跃率（MAU/注册）   | 30% | 50%+ | <20% |

## 七、立项汇报的叙事结构

拿到数据后，建议用以下逻辑链组织汇报：

```
1. 客户现状（痛点）
   "OPC 卖家花 2-3 天做一套广告素材，ROAS 平均只有 X，
    60% 的人第一次投放就亏钱。"

2. 我们做了什么（实验）
   "我们对 N 个真实客户做了对照实验，隔离了素材、定向、出价三个变量。"

3. 效果差异（硬数据）
   "AI 素材组 CTR 提升 X%，全链路 ROAS 提升 Y%，
    其中素材贡献 a%，定向贡献 b%，协同效应 c%。"

4. 不同客户的差异（分层洞察）
   "对初级素材型客户价值最大（ROAS +Z%），
    最佳品类是 XX，最佳预算段是 $XXX-$XXXX。"

5. 客户愿意付费（行为数据）
   "Free → Pro 转化率 X%，首月续费率 X%，
    付费触发点是 XX 功能。"

6. 我们的优势（为什么是我们）
   "已有 $10M+ 投放经验 + Claw Skill 92% 完成率 + XX 可复用。"

7. 资源需求和回报预期
   "MVP 需要 X 人 X 个月，达到 X 个付费用户即盈亏平衡。"
```
